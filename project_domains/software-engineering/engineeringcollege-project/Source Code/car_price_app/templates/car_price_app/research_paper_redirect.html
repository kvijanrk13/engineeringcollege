Abstract Summary

K-RADIUS+ is a novel hybrid algorithm combining Apriori association rule mining, a 15-factor explainable depreciation formula, buyer confidence scoring (0-100), and risk categorization. Unlike commercial platforms (Spinny, Cars24, Gaddi, OLX), K-RADIUS+ publishes its complete mathematical formula for transparency and reproducibility.

Key Novel Contributions

  • First published hybrid algorithm integrating Apriori mining + multiplicative depreciation + confidence scoring
  • 15 named factors with documented weights (vs. black-box models)
  • Odometer tampering risk detection based on verification source
  • Buyer Confidence Score (0-100) with Low/Medium/High Risk flags
  • Local RTO/city-specific pricing for Khammam, Telangana
  • Seller advice engine with actionable pre-sale recommendations
  • Fully reproducible - all code published, all formulas documented

Mathematical Formula (Core)

Predicted Price = Base Price
               x Age Factor x KM Factor x Odometer Factor x Repair Factor
               x Colour Factor x Owner Factor x Insurance Factor x Service Factor
               x Accident Factor x Challan Factor x Tyre Factor x Body Factor
               x Usage Factor x Urgency Factor x Local Factor x K-RADIUS Adjustment
