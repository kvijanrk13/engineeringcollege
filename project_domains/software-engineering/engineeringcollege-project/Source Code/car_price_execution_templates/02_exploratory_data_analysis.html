Step 2: Exploratory Data Analysis

Purpose: Visualize price patterns by fuel type, seller type, transmission, and correlations.

Code

import matplotlib.pyplot as plt import seaborn as sns fig, axes = plt.subplots(1, 3, figsize=(15, 5), sharey=True) sns.barplot(x='Fuel_Type', y='Selling_Price', data=car_data, ax=axes[0]) sns.barplot(x='Seller_Type', y='Selling_Price', data=car_data, ax=axes[1]) sns.barplot(x='Transmission', y='Selling_Price', data=car_data, ax=axes[2]) numeric_columns = car_data.select_dtypes(include=['float64', 'int64']).columns sns.heatmap(car_data[numeric_columns].corr(), annot=True) plt.title('Correlation between the columns') plt.show()
📝 Modification Guide:
  • Add subplots: Change figsize or add more subplot categories
  • Customize plots: Modify colors with palette='Set2' or other seaborn palettes
  • Change analysis: Replace barplot with histplot, boxplot, or violinplot
  • Save figures: Add plt.savefig('plot_name.png') before plt.show()
  • Add distributions: Create subplots for univariate distributions

Expected Output

  • Bar charts showing average price by Fuel Type, Seller Type, Transmission
  • Correlation heatmap showing relationships between numeric columns
  • Visual patterns in price distribution
