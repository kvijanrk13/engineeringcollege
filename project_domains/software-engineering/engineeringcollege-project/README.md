# EngineeringCollege Project

This project uses the repository's main Django source tree.

Domain-specific project metadata is registered in the parent `projects.json`.
The downloadable ZIP is generated from the current deployed source and includes
the complete `project_domains/` hierarchy.

## Folder Structure

This Software Engineering project folder is organized for student submission and download:

- `Source Code/` - notes for the executable Django source generated in the ZIP
- `Modules/` - module breakdown and implementation notes
- `Documentation/` - local setup guide, report outline, and viva notes
- `PPT/` - presentation outline or slide deck
- `Video/` - demo script or video link notes
- `Test Cases/` - manual and Django test case notes
- `UML Diagrams/` - use case, activity, class, component, and deployment diagrams
- `Databases/` - database configuration, model/schema, migration, and backup notes

In the paid ZIP, the runnable Django project source is generated under `Project Source/`.
