# Presentation Outline

## Slide 1: Title

Predicting Second Hand Cars Price using Machine Learning Algorithms

## Slide 2: Problem Statement

Second-hand car prices vary based on age, mileage, fuel type, ownership, seller type, transmission, and market condition.

## Slide 3: Objectives

- Predict car resale price
- Study depreciation behavior
- Compare regression models
- Use Apriori rules for data-mining interpretation

## Slide 4: Dataset

Public Kaggle car datasets and generated Maruti Suzuki Khammam sample data.

## Slide 5: Methodology

Data preprocessing, feature engineering, model training, evaluation, and Django execution.

## Slide 6: Algorithms

Linear Regression, Ridge, Lasso, Random Forest, Gradient Boosting, and Apriori.

## Slide 7: System Architecture

Django UI, dataset loader, ML scripts, Apriori module, and model artifacts.

## Slide 8: Results

Show model metrics, prediction output, and Apriori rules.

## Slide 9: Demo

Run migrations, start server, open local app, train model, and predict price.

## Slide 10: Conclusion

The system gives a reproducible local workflow for second-hand car price prediction and data-mining analysis.
