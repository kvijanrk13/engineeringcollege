# Project Content Index

This package mirrors the academic structure used by the Engineering College project, but it is scoped only to the Car Price Prediction data mining project. It intentionally excludes payment-gateway and cloud-media-storage integrations.

## Folder Contents

- `Source Code/`: standalone Django project, data loading scripts, model training, Apriori mining, prediction CLI, requirements, and automated tests.
- `datasets/`: local car datasets used for training, Apriori mining, and demonstration.
- `Modules/`: module-level breakdown for data ingestion, preprocessing, modelling, prediction, web execution, and reporting.
- `Databases/`: SQLite schema notes and SQL reference for the local registration and execution-log database.
- `UML Diagrams/`: PlantUML source files for use case, class, activity, sequence, component, deployment, and ER diagrams.
- `Test Cases/`: manual, command-line, web, and automated test case documentation.
- `Documentation/`: project synopsis, full documentation, local run guide, report outline, and execution notes.
- `PPT/`: presentation outline and generated slide deck for project viva/demo.
- `Video/`: demo script for recording the execution workflow.

## Excluded Topics

- Payment screens, payment callbacks, QR images, order tracking, and receipt workflows.
- Cloud upload, private download, media migration, or remote asset storage workflows.
- Engineering College faculty/student certificate management features.
