# Synopsis

## Title

Used Car Price Prediction Using K-Radius Nearest Neighbors

## Domain

Data Mining and Machine Learning

## Problem Statement

Second-hand car prices vary due to age, kilometers driven, fuel type, transmission, seller type, ownership count, engine capacity, brand reputation, and vehicle condition. Manual estimation is inconsistent, so this project builds a data-driven prediction and analysis system.

## Proposed System

The proposed system loads historical car records, preprocesses noisy dataset fields, trains a machine learning model, predicts resale prices, and mines association rules for interpretable price/depreciation patterns.

## Technologies

- Python
- Django
- SQLite
- pandas
- scikit-learn
- joblib
- mlxtend-style Apriori logic implemented locally

## Expected Result

A working local web application and command-line ML workflow that predicts used-car price and explains common data mining patterns affecting resale value.
