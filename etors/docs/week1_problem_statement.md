# ETORS Week 1 - Problem Statement

## Problem Statement
The ETORS system is an academic online railway reservation system that demonstrates how a train ticket booking workflow can be modeled in a web application. The system should allow users to search trains, view seat availability, book tickets, track PNR status, and optionally request a cab for station transfer.

## Objectives
- Provide a simple interface for searching trains by source, destination, and journey date.
- Show live seat availability for demo trains.
- Enable dummy ticket booking with a generated PNR.
- Support PNR verification using the registered mobile number.
- Demonstrate an integrated BOOKMYCAB flow for travel convenience.

## Functional Requirements
1. The system should allow users to search for trains between selected stations.
2. The system should display train details such as name, departure time, arrival time, and duration.
3. The system should allow a user to book a ticket after logging in with a verified Gmail account.
4. The system should generate a unique PNR for successful booking.
5. The system should allow users to verify PNR status securely.
6. The system should support dummy payment and reservation confirmation.

## Non-Functional Requirements
- The interface should be simple and easy to use.
- The system should provide clear feedback for errors and success messages.
- The application should be responsive and accessible on desktop and mobile screens.

## Scope
The scope of ETORS includes train search, booking, payment simulation, PNR status tracking, and cab booking integration. It is intended as a classroom demonstration and not a real railway reservation system.
