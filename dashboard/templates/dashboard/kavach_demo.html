Internal System Design

  1. Sender opens /projects/kavach/ and uploads a file.
  2. The server generates a random AES key and random nonce/IV.
  3. The server encrypts the file with AES-GCM and stores only the encrypted .aesgcm file.
  4. The page creates a transfer ID and access code for the receiver workflow.
  5. Receiver opens the same link, enters the transfer ID and access code, and downloads the decrypted file.
