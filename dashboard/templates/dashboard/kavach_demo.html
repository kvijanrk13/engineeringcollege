Beginner Execution Flow

  1. Open the KAVACH project from the Security domain under /projects/.
  2. Click Open Demo in New Tab to reach this execution page.
  3. For local execution, start the standalone KAVACH server from its Source Code folder.
  4. Open the local registration page and create a user account.
  5. After registration, the profile page confirms that the RSA public/private key pair was generated.
  6. Open Upload Text File and select a Notepad .txt file.
  7. Open My Files to see the uploaded text file and preview content.
  8. The public key can be shared with others. The private key is encrypted with the user's password.
