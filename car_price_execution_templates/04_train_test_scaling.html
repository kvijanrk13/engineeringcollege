Step 4: Train/Test Split & Scaling

Purpose: Prepare train/test data and scale numeric features before model training.

Code

from sklearn.model_selection import train_test_split from sklearn.preprocessing import StandardScaler X_train, X_test, y_train, y_test = train_test_split( X, y, test_size=0.3, random_state=42, ) scaler = StandardScaler() X_train = scaler.fit_transform(X_train) X_test = scaler.transform(X_test)
📝 Modification Guide:
  • Change train/test ratio: Modify test_size (0.2 for 80/20 split, 0.25 for 75/25, etc.)
  • Use different scaler: Replace StandardScaler with MinMaxScaler or RobustScaler
  • K-Fold Cross-Validation: Use KFold instead of simple train/test split
  • Stratified split: Add stratify=y for classification tasks
  • Save scaler: Add pickle.dump(scaler, open('scaler.pkl', 'wb'))
  • Verify shapes: Add print statements: print(X_train.shape, X_test.shape)

Expected Output

  • X_train and X_test: Feature matrices (scaled to mean=0, std=1)
  • y_train and y_test: Target vectors
  • Training set size: ~70% of original data
  • Test set size: ~30% of original data
  • All features normalized to comparable scales
