Step 6: Cross Validation

Purpose: Validate the model performance across multiple folds to ensure generalization.

Code

from sklearn.model_selection import cross_val_score import numpy as np for name, model in models.items(): scores = cross_val_score(model, X, y, cv=5, scoring='r2') print(name, 'Average R2:', np.mean(scores))
📝 Modification Guide:
  • Change CV folds: Modify cv=5 to cv=10 or cv=3 for different validation strategies
  • Different scoring metrics: Use scoring='neg_mean_absolute_error' or 'neg_mean_squared_error'
  • Add statistics: Print std, min, max along with mean scores
  • Visualize results: Create box plots of cross-validation scores
  • Use StratifiedKFold: For classification tasks or imbalanced datasets
  • Time series split: Use TimeSeriesSplit for temporal data
  • Add hyperparameter tuning: Combine with GridSearchCV or RandomizedSearchCV

Expected Output

  • Average R2 Score for each model across 5 folds
  • Shows consistency of model performance
  • Helps identify overfitting (high train R2, low CV R2)
  • Provides confidence in model selection
