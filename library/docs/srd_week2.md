# Week 2 - Software Requirements

| Type | Essential requirements |
|---|---|
| Functional | Login, search books, request/approve issues, return books, calculate fines, and pay fines |
| Security | Role-based access, CSRF protection, and verified payments |
| Data | Author, Book, Student, Issue, Fine, and LibraryStat |
| External services | PostgreSQL, Cloudinary, and Razorpay |
| Acceptance | Authorized users complete the issue-return-fine workflow successfully |
