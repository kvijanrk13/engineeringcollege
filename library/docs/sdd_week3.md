# Week 3 - Software Design

| Area | Design |
|---|---|
| Architecture | Django Model-Template-View |
| Modules | Student, Library, Issue/Return, Fine, and Documentation |
| Database | Django ORM with PostgreSQL |
| Services | Cloudinary media and Razorpay payments |
| Deployment | Browser → Render/Gunicorn/Django → PostgreSQL |

**Workflow:** Login → Search → Request → Approve → Return → Fine/Payment.
