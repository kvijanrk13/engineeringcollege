Software Engineering Lab - II-I CSE(AI&ML)

Documentation and Lab Manual

1. Development of Problem Statements

Identify and define real-world problems. Gather requirements from stakeholders. Analyze feasibility and scope. Document problem statements clearly with objectives, constraints, and expected outcomes.

2. Preparation of Software Requirement Specification Document, Design Documents and Testing Phase Documents

Create Software Requirement Specification (SRS) with functional and non-functional requirements. Develop design documents including system architecture, module design, and data flow diagrams. Prepare test plans, test cases, and testing phase documentation covering unit, integration, and system testing.

3. Preparation of Software Configuration Management and Risk Management Documents

Document software configuration management plans including version control, change management, and baseline identification. Prepare risk management documents with risk identification, analysis, mitigation strategies, and contingency plans.

4. Study and Usage of Design Phase CASE Tools

Learn Computer-Aided Software Engineering (CASE) tools used in the design phase. Study tools like UML designers, diagramming tools, and modeling software. Understand how these tools improve design quality, consistency, and documentation.

5. Performing the Design by Using Design Phase CASE Tools

Apply CASE tools to create system designs. Generate UML diagrams including use case, class, sequence, and activity diagrams. Use modeling tools to design system architecture and module interactions. Validate designs against requirements.

6. Develop Test Cases for Unit Testing and Integration Testing

Design test cases for individual modules and components. Create unit test cases covering all functions, methods, and edge cases. Develop integration test cases to verify module interactions and data flow. Document expected results and pass/fail criteria.

7. Develop Test Cases for Various White Box and Black Box Testing Techniques

Create white box test cases using statement coverage, branch coverage, and path coverage techniques. Develop black box test cases using equivalence partitioning, boundary value analysis, decision table testing, and state transition testing. Document test scenarios and expected outcomes.
