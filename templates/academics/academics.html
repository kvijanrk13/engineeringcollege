Step-by-step: from one full adder to eight arithmetic operations

The lesson begins with the general arithmetic-circuit rule and then expands it into a four-bit circuit. Follow these steps before running the animation.

  1. Identify the two four-bit operands. Register A supplies A₃A₂A₁A₀ directly to the X input of the four full adders. Register B supplies B₃B₂B₁B₀ to the multiplexers. Bit 0 is the least-significant stage, so calculation starts at FA₀.
  2. Place one 4×1 multiplexer before every full adder. MUXi has four possible inputs: I₀ = Bi, I₁ = B̅i, I₂ = 0 and I₃ = 1. The same select lines S₁ and S₀ control all four multiplexers, so they construct one complete four-bit word Y.
  3. Decode the common select lines. S₁S₀ = 00 selects B, 01 selects B̅, 10 selects 0000, and 11 selects 1111. The selected bit from each MUX becomes Yi, the second data input of FAi.
  4. Choose the initial carry. Cin enters FA₀ and acts as an extra 0 or 1. It is also a control variable: changing only Cin changes each selected MUX function into a second microoperation.
  5. Apply the general arithmetic equation. The four-bit network always evaluates the same expression; only Y and Cin change.
  6. Evaluate from right to left. At stage i, calculate Di = Ai ⊕ Yi ⊕ Ci. Then calculate Ci+1 = AiYi + Ci(Ai ⊕ Yi). Carry Ci+1 ripples into the next full adder.
  7. Read the result. After FA₃ settles, D₃D₂D₁D₀ is the four-bit result and C₄ is the final carry. For subtraction, the four D bits are the two’s-complement result; for transfer A with S₁S₀Cin = 111, C₄ is expected to be 1.
Y = MUX(S₁S₀; B, B̅, 0000, 1111)
D = A + Y + Cᵢₙ

Derive all eight microoperations

000 → A + BSelect B and add no input carry: ordinary addition.
001 → A + B + 1Select B and add Cin = 1: addition with carry.
010 → A + B̅Since B̅ = (2⁴ − 1) − B, this gives A − B − 1 modulo 16: subtract with borrow.
011 → A + B̅ + 1B̅ + 1 is the two’s complement of B, so this is A − B.
100 → A + 0000The MUX supplies zero and Cin = 0, so the circuit transfers A unchanged.
101 → A + 0000 + 1The added carry increments A by one.
110 → A + 11111111 represents −1 modulo 16, so the four-bit result is A − 1.
111 → A + 1111 + 1The added value is binary 1 0000; D reproduces A and C₄ becomes 1.

Worked example: subtraction A − B

Let A = 9 = 1001₂ and B = 5 = 0101₂. Choose S₁S₀ = 01 and Cin = 1. The multiplexers select B̅ = 1010, so the circuit computes 1001 + 1010 + 1.

What is OLAP?

OnLine Analytical Processing is a technology for examining large amounts of historical data from several perspectives. It organizes measures such as sales, profit, or student performance inside a multidimensional cube so users can summarize data, compare trends, and discover patterns quickly.
